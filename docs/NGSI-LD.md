# NGSI-LD

## Example queries

### Geoquery Language

<https://cim.etsi.org/NGSI-LD/official/clause-4.html#4.10>

```shell
docker compose exec phpfpm curl --verbose --header 'accept: application/geo+json' --get \
    'http://scorpio.local:9090/ngsi-ld/v1/entities' \
    --data 'georel=near;maxDistance==2000' \
    --data 'geometry=Point' \
    --data 'coordinates=[10.198712,56.1551091]'
```

> [!IMPORTANT]
> URL encoding query string values (e.g. with `--data-urlencode`) will break the query!

---
